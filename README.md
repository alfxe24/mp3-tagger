# How To Use

## Downloading the App & Python
First, download Python from [the Python website](https://www.python.org/downloads/). Then, from [the GitHub page](https://github.com/alfxe24/mp3-tagger), press the blue `Code` button, and `Download ZIP`. Unzip this, and from inside the `main` folder, open `main.py`.

## Editing Files
First, select the root directory (folder) of your music files / folders. This will then show a menu of all of your folders and songs. Select the folder containing the songs you want to edit, you should select a folder that contains .mp3 files itself, not a folder that contains folders of mp3 files. Once you have clicked on your desired folder, press `submit`.

Next, you will have a list of the .mp3 files accessible from within that folder. From here, you can input the information you want to change. To use the autofill, enter text in the bottom entry box of the column you want to autofill, and press the `Fill Above` button for that row. Once you are happy, press `Submit` to submit your changes.

From here you can press the `Back` button to be brought back to the root directory you selected to allow you to edit more files.

NOTE: The editor will only change non-blank entry boxes, so don't feel the need to fill them all.
